# Alumni Tracking System

A full-stack web application built using the MERN stack to connect alumni, manage alumni profiles, and support community interaction.

## Technologies Used

- MongoDB — Database
- Express.js — Backend framework
- React.js — Frontend library
- Node.js — Runtime environment
- JWT — Authentication

## Features

- User registration and login
- Alumni profile management
- Alumni directory
- Community posts
- Likes and comments
- Frequently Asked Questions (FAQs)
- Admin dashboard
- Search alumni profiles

## Setup

The frontend and backend require Node.js and a configured MongoDB database.

1. Configure the backend environment variables.
2. Install backend dependencies using `npm install` inside `server`.
3. Start the backend using `npm run dev`.
4. Install frontend dependencies using `npm install` inside `client`.
5. Start the frontend using `npm run dev`.

## Purpose

This project demonstrates full-stack development, database integration, authentication, and community management.
